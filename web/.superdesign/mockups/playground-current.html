ShopNexus API

Download OpenAPI Document

The HTTP contract between the ShopNexus app and its server. The server validates every request against this document, and the end-to-end suite validates every response against it. The docs site explains each module: https://docs.shopnexus.id.vn/en/api.

Signing in

  1. POST /v1/auth/email-codes mails a six-digit code to an email address.
  2. POST /v1/auth/sign-in with that code returns an access token and a refresh token. The first sign-in of an address creates the account.
  3. Send the access token as Authorization: Bearer <token>. It lasts 15 minutes.
