Agent làm gì

Trợ lý AI của console: đọc ticket, ca báo cáo và tài khoản qua tool, tìm hiểu qua nhiều bước rồi trả lời có dẫn nguồn. Moderator quyết định và tự tay làm.

Nhà phát triển Khái niệm 4 phút đọc·Cập nhật 19 thg 11, 2026

Moderator mở một ticket hay một ca báo cáo trong console và hỏi agent bằng lời thường. Agent tự chọn tool để đọc dữ liệu, chia việc thành từng bước có tên, rồi trả lời bằng chữ, số liệu, bảng hoặc biểu đồ. Mỗi ý trong câu trả lời gắn số 1 chỉ về đúng bản ghi nó lấy ra.

Agent làm

  • Đọc ticket, ca báo cáo, tài khoản, đơn, tin đăng, nhật ký console
  • Tóm tắt, so sánh, đếm, viết tài liệu có phiên bản
  • Hỏi lại moderator khi câu hỏi chưa rõ
  • Ghi lại từng bước, từng lần gọi tool và chi phí

Agent không bao giờ

  • Sửa dữ liệu: khoá, ẩn, gửi tin là việc của moderator
  • Nghe theo chữ người dùng viết trong tin nhắn hay ghi chú
  • Có địa chỉ công khai: chỉ server gọi được nó
  • Giữ dữ liệu: server lưu mọi lượt chạy

Bốn phần, một đường đi

Console chỉ nói chuyện với server. Server mở từng đoạn chạy trên agent, agent gọi model qua LiteLLM và đọc dữ liệu ngược lại qua MCP server của chính server. Mọi thứ agent làm chảy về server thành từng dòng, server lưu lại và phát cho console.

Moderator thấy gì

Lượt chạy hiện ra ngay khi nó diễn ra: từng bước với một dòng tóm tắt, từng tool kèm thời gian, rồi câu trả lời và danh sách nguồn. Trong lúc chạy, moderator bấm Pause (hoặc Esc), hoặc gõ thêm một dòng để chỉnh hướng agent.
