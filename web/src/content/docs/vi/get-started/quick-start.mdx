<Prereqs time="30 phút" who="Lập trình viên">
- Docker có Compose, và một tài khoản GitHub có quyền vào repository riêng tư `clients`.
- Cho ứng dụng Android: JDK 21, Android SDK có platform 36, và một điện thoại Android 12 trở lên (hoặc emulator). Thêm Go 1.27 để chạy server trên máy cho ứng dụng gọi.
- Bun, để xem trước tài liệu khi chạy riêng.
</Prereqs>

## Toàn bộ hệ thống

<Steps>
<Step title="Clone">
```bash title="Terminal"
git clone --recurse-submodules https://github.com/shopnexus/shopnexus.git
cd shopnexus
```
</Step>

<Step title="Thêm khóa cho mô hình">
Mọi lần gọi mô hình đều đi qua Bifrost của stack, và Bifrost cần các khóa upstream. Tạo file `infra/stack/secrets/compose.env` có `LLM_UPSTREAM_API_KEY` và `OPENROUTER_API_KEY`. File này không được commit. Thiếu khóa thì mọi lần gọi mô hình đều lỗi: tìm kiếm chỉ đọc nguyên văn các từ, còn bước đọc tin đăng và trợ lý AI trên trang điều hành đều lỗi.
</Step>

<Step title="Bật stack dev">
```bash title="Terminal"
make dev
```

Lần đầu, lệnh này build các image, ghi các khóa của stack và tải khoảng 5 GB file mô hình, nên sẽ mất một lúc. Những lần sau dùng lại tất cả. Sau đó server, website, trang điều hành, tài liệu và agent tự tải lại từ mã nguồn mỗi khi lưu file.
</Step>

<Step title="Mở hệ thống">
Website ở `http://shopnexus.localhost:56481`, API ở `http://api.shopnexus.localhost:56481` và trang điều hành ở `http://console.shopnexus.localhost:56481`. `GET /healthz` trên API trả lời ngay khi process chạy, còn `GET /readyz` kiểm tra thêm Postgres và Restate. Trang [Stack local](/vi/operations/local-stack) liệt kê mọi host.
</Step>

<Step title="Nạp dữ liệu và đăng nhập trang điều hành">
Database lúc đầu trống. `docker compose exec server-dev go run ./cmd/devseed` nạp một sàn mẫu nhỏ. API không tạo được tài khoản nhân viên: `docker compose exec server-dev go run ./cmd/console create-admin --email <email> --name <tên>` tạo một quản trị viên và in ra mật khẩu tạm.
</Step>
</Steps>

`make down` tắt các stack và giữ nguyên dữ liệu. `make prod` chạy đúng các image mà cụm máy chủ chạy, ở cổng 56480, còn `make test` chạy test của server.

## Ứng dụng Android

Trong thư mục `clients/app-android/`, với điện thoại đã kết nối qua adb:

```bash title="Terminal"
./run.sh        # cài bản debug rồi mở ứng dụng
./run.sh -w     # cài lại và mở lại sau mỗi lần lưu file
```

Script ưu tiên điện thoại thật hơn emulator. Muốn dùng emulator thì đặt `ANDROID_SERIAL`. Flavor mặc định `live` gọi server trên máy tính ở `127.0.0.1:8080`, mà stack dev không mở cổng này: hãy chạy riêng server bằng `make run` trong `server/` (xem [Chạy riêng server](/vi/operations/local-stack#chạy-riêng-server)). `run.sh` chuyển tiếp các cổng sang điện thoại.

`FLAVOR=demo ./run.sh` chạy offline bằng dữ liệu mẫu, có người bán và hãng vận chuyển giả lập. Ở bản debug, nhấn giữ một tiêu đề hoặc nút vị trí trên trang chủ để mở debug panel.

## Tài liệu này

Stack dev phục vụ tài liệu ở `http://docs.shopnexus.localhost:56481`. Khi chạy riêng, trong `docs/web`, chạy `bun install` rồi `bun run dev` để xem trước tại `http://localhost:4321`. Tìm kiếm chỉ chạy sau khi đã `bun run build` một lần, vì bước build mới ghi chỉ mục tìm kiếm.
