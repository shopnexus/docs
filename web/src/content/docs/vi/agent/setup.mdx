Server là nơi duy nhất giữ cấu hình của một agent. Agent không có bản sao: mỗi đoạn chạy nhận cấu hình trong các trường `agent_config` và `gateway` của `POST /runs`.

## Agent trong `ai_agents`

Bảng `ai_agents` của server có hai loại agent. Migration 0056 tạo sẵn các dòng đầu.

| Loại | Agent tạo sẵn | Ai dùng | Admin làm được |
|---|---|---|---|
| `console` | Console assistant (`console-agent`) | moderator chọn trong ô hỏi | tạo, sửa, bật, tắt |
| `app` | Scam check, Listing photo reader, Search, Search embeddings | code của server gọi | đổi model, giới hạn, ngân sách |

Một agent có tên hiển thị ("Console assistant") và một slug (`console-agent`), cũng là tên team của nó trong Bifrost. Mỗi lần lưu hướng dẫn mới, server thêm một phiên bản vào `ai_agent_versions` với người sửa và thời điểm. Câu hỏi không chọn agent dùng Console assistant; agent không tồn tại hay là agent `app` thì trả 404 `ai_agent_not_found`, agent đã tắt thì 409 `ai_agent_disabled`.

Admin quản lý agent trong **Settings** của console. Trang của một agent giữ model (nhà cung cấp và model), các model dự phòng, ngân sách tháng và giới hạn tốc độ của các bên gọi; mỗi model có một giá. Trang Providers chỉ để xem, vì thêm nhà cung cấp là việc của infra. Server ghi team, virtual key, ngân sách và giá vào Bifrost qua admin API của nó ([Cổng Bifrost](/vi/operations/cluster/llm-gateway#key-và-ngân-sách)).

## Cấu hình theo đoạn chạy

```jsonc
"agent_config": {
  "id": "uuid", "name": "Console assistant",
  "instructions": "…", "instructions_version": 3,
  "tools": ["ticket_get", "account_get"],  // tool MCP agent được dùng
  "limits": { "deadline_s": 60, "max_model_calls": 40, "context_window": 128000,
              "tool_timeout_s": 20, "tool_attempts": 3, "max_tokens": 4096 }
},
"gateway": {
  "key": "sk-bf-…",                         // virtual key của agent trong Bifrost
  "model": "upstream/claude-sonnet-5-5",   // provider/model
  "fallbacks": [],                         // provider/model, thử lần lượt
  "prices": { "upstream/claude-sonnet-5-5": { "input": 2e-6, "output": 1e-5, "cache_read": null, "cache_write": null } }
}
```

Agent bỏ khóa lạ của `agent_config`; giá trị ngoài khoảng cho phép thì cả request bị từ chối 400. Đoạn chạy thiếu `gateway` cũng bị từ chối 400. Agent không bao giờ ghi log hay lưu key, và tính giá mỗi lần gọi theo `prices` (USD cho mỗi token; giá cache để null thì bằng giá input). System prompt của đoạn gồm prompt có sẵn (vai trò, bản ghi đang mở, quy tắc kiểm duyệt và hỗ trợ), quy tắc của output tool, `instructions` của agent và prompt của skill nếu câu hỏi dùng skill.

## Biến môi trường

Các giá trị giống nhau ở compose và mọi stack nằm trong `infra/stack/env/agent.env`; chart đọc file này, compose đọc nó qua `env_file`. Hai token nằm trong file `.env` của volume keys. Agent không giữ key model nào của riêng nó.

| Biến | Phía | Ý nghĩa |
|---|---|---|
| `AGENT_BASE_URL` | server | Địa chỉ nội bộ của agent, như `http://agent-dev:3000` |
| `AGENT_SERVICE_TOKEN` | cả hai | Token server gửi kèm `POST /runs`; rỗng thì agent từ chối mọi request |
| `AGENT_MCP_ADDR` | server | Cổng của MCP server, `0.0.0.0:9090` |
| `AGENT_MCP_TOKEN` | cả hai | Token agent gửi tới MCP và endpoint điều khiển |
| `MCP_SERVER_URL` | agent | `/mcp` của server, như `http://server-dev:9090/mcp`; origin của nó cũng phục vụ endpoint điều khiển |
| `GATEWAY_BASE_URL` | agent | Endpoint tương thích OpenAI của Bifrost, `http://bifrost:8080/v1` |
| `GATEWAY_URL`, `GATEWAY_ADMIN_USERNAME`, `GATEWAY_ADMIN_PASSWORD` | server | Admin API của Bifrost, cho bộ đối soát và trang Settings |
| `AGENT_TURN_DEADLINE_MS` | agent | Thời hạn mặc định của một đoạn, 60 000 |
| `FEATURE_ALL_AGENT`, `FEATURE_LLM` | agent | `false` thì mọi đoạn chạy bị từ chối 503 |

Mỗi token dài ít nhất 32 ký tự; `cmd/envgen` của server sinh cả hai. Không dòng log nào ghi token hay key của cổng. Danh sách đầy đủ của agent ở `agent/.env.example` và `agent/src/config.ts`.

## Chạy thử ở máy

Agent không có file compose riêng. Nó chạy trên Bifrost và MCP của stack, từ `docker-compose.yml` của repo umbrella hoặc từ cluster.

```bash
cd agent
npm install
cp .env.example .env
# Điền AGENT_SERVICE_TOKEN, AGENT_MCP_TOKEN, MCP_SERVER_URL, GATEWAY_BASE_URL và CLI_GATEWAY_KEY theo stack.
npm run start:dev
npm run chat -- "Có bao nhiêu ticket đang mở?"
```

`npm run chat` gửi một đoạn `new` tới agent trên `PORT` với tư cách `CLI_MEMBER_ID`, kèm `CLI_GATEWAY_KEY` và `CLI_GATEWAY_MODEL` làm `gateway` với giá bằng 0, rồi in các event và dòng `end`. Lấy key từ team `console-agent` trong UI của Bifrost. Lệnh gọi model và MCP thật, nên có thể tốn tiền. Không có endpoint điều khiển của server thì các lần hỏi lệnh lỗi và đoạn chạy tiếp tục mà không có Pause, Stop now hay cập nhật.

## Kiểm thử

```bash
npm run build
npm run typecheck
npm test                  # chạy offline
npm run test:live-cache   # gọi Bifrost thật, bỏ qua khi thiếu LIVE_GATEWAY_URL và LIVE_GATEWAY_KEY
```

`npm test` dùng một model có kịch bản, một server giả trên 127.0.0.1 (MCP server có cả tool đọc lẫn tool ghi, và endpoint điều khiển) và một bộ gom dòng trong bộ nhớ. Bộ test phủ token, các lỗi 400 và 503, định dạng NDJSON, bước, số dẫn nguồn, tài liệu, thử lại tool, `ask_user`, tạm dừng và chạy tiếp, cập nhật giữa chừng, Stop now, ngân sách, thời hạn và tóm tắt ngữ cảnh.
