A moderator opens a ticket, a report case or an account in the console and asks the agent a question in plain words. The agent picks tools to read the data, splits the work into named steps and answers with text, key figures, tables or charts. Each claim in the answer carries a number such as <span class="run-cite">1</span> that points to the record it came from.

The read-only rule is <Req id="BR-MOD-03" />. The agent has no tool that changes data, so a prompt injection hidden in a user's message can at worst produce a wrong proposal, which a moderator then reviews.

## The four parts

The console calls only the server. The server starts each run segment on the agent. The agent calls the model through LiteLLM and reads data through the MCP server that the server opens on a port of its own. Everything the agent does flows back to the server as lines; the server stores them and sends them on to the console.

The agent is a NestJS service of its own in the `shopnexus/agent` repo, running a Strands loop on the model LiteLLM picks. The decision to run it apart and have it read through the server's MCP is <Req id="ADR-0003" />.

## The moderator's screen

A run shows up as it happens: each step with a one-line summary, each tool call with its timing, then the answer and its sources. While it runs, the moderator presses **Pause** (or Esc), or types a line to steer the agent.

<RunPreview caption="A finished run on a report case. The data is an example." />

<Callout type="note">
When the agent proposes suspending an account, the moderator presses the console's suspend button as always. The action goes through the console's endpoint and into the audit log under the moderator's name.
</Callout>

## One chat per record

A ticket, a report case or an account has one chat, shared by every moderator who opens it, so the next shift sees what was asked, and each question shows who asked it. A chat with no record belongs to the moderator who opened it. Use cases: <Req id="UC-MOD-06" />, <Req id="UC-MOD-07" />, <Req id="UC-MOD-08" />.
