# Real carriers, GHTK and GHN: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sellers link their own GHTK and GHN accounts; ShopNexus makes `linked` shipments and reads `manual` codes with the seller's token; webhooks and a poll move shipments on. The app follows on fake data.

**Architecture:** A new server module `shipping` owns carrier accounts (encrypted tokens), the carrier clients and the webhooks; `deal` asks it to make, read and cancel shipments and polls open shipments from `OrderTimers`. `shipping` never imports `deal`: the app wiring hands it two functions of the deal service. The app mirrors the model on fake data.

**Tech Stack:** Go (server2: net/http, pgx, Restate SDK), Postgres; Kotlin, Compose, Hilt (app2).

**Spec:** `~/shopnexus/docs/superpowers/specs/2026-11-13-carrier-integration-design.md` (part 2 of `2026-11-12-order-flow-sync-design.md`).

## Global Constraints

- Decisions from the spec, not to be reopened: GHTK and GHN only; at most one account per seller per carrier; GHTK links by email and password through `POST /services/shops/token` with ShopNexus's partner token, the password never stored; GHN links by token and ShopId, checked against GHN's shop list; tokens AES-GCM under `CARRIER_TOKEN_KEY`, never in a response, log or console; unlinking refused while a shipment at that carrier is open (`shipments_open`); deleting an account deletes its tokens; `manual` codes read with the seller's own token; `linked` shipments carry `carrier` and `pickup_from` (`{carrier_pickup_id}` or `{address_id}`) and the order keeps a copy of the pickup; webhooks `POST /v1/carriers/{ghtk|ghn}/webhook/{secret}` answer 404 on a wrong secret and 200 otherwise; a poll every `CARRIER_POLL_EVERY` (2 h) per open shipment; `CARRIER` is `fake | none | live`, `APP_ENV=prod` refuses `fake`; the fake links anything but the password or token `wrong`; payout leaves Thiết lập COD.

## Review Focus

1. A webhook for a code no order has, or for a closed order: GHTK retries once on a non-200, so the handler must still answer 200 and change nothing. Task 3 `TestWebhookForAnUnknownCodeAnswers200`.
2. The pickup timeout on a `linked` shipment the carrier already picked up: cancel fails ("Đơn đã lấy hàng, không thể hủy đơn."), and the order must still be cancelled and the listing released, not retried forever. The release goes before the cancel. Task 4 `TestPickupTimeoutReleasesBeforeCallingOff`.
3. A seller unlinks GHTK while a GHN shipment is open: allowed, because the open shipment is at another carrier. Task 3 `TestUnlinkCountsOnlyThatCarrier`.
4. `CARRIER=none`: lookup, create and edit answer 503 before any "not linked" check, as part 1's e2e expects. Task 4 `TestNoCarrierAnswers503BeforeLinking`.
5. A token decrypted with another environment's key fails cleanly (500 with no token in the log), and relinking replaces it. Task 3 `TestAWrongKeyDoesNotOpenTheToken`.

## Rulings made while planning

- `shipping` must not import `deal` (deal imports shipping). The app wiring gives `shipping.Deps.Deals` two functions, `ShipmentUpdated(ctx, code, status)` and `OpenShipmentsAt(ctx, seller, carrier)`, closed over the deal service built after it.
- The poll lives in `deal`'s `OrderTimers` (it knows the order, the seller and when the order closes); it reads through `shipping.Lookup` and moves the order through the existing `ShipmentUpdates` flow.
- `CARRIER=none` is an empty client map in `shipping`; `carrier.None` goes. Every shipping call with no clients answers `carrier.ErrUnavailable` first.
- Part 1 fixed a linked shipment's carrier to GHTK; it now comes from the request (`ghtk` or `ghn`).
- The reviewer's deferred minor on part 1 ("release before calling off") is fixed here, because the call off is real now.
- The app keeps its GHTK "open a new account" path (`CarrierLink.GHTK_NEW`, fake only); the server has no endpoint for it in this part.
- Deviations from the spec's API table: `GET /v1/carrier-accounts/{carrier}/pickups` answers 409 `carrier_not_linked` when not linked (the spec said 404), to match create, edit, lookup and quote; the quote takes `order_id`, because the fee depends on the recipient's address; `GHN_API_URL` holds the whole base with `/shiip/public-api` (dev `https://dev-online-gateway.ghn.vn/shiip/public-api`), so the client's paths start at `/v2` and `/master-data`.
- The spec says `None` stays as a client; the plan drops it for an empty client map, which answers the same `ErrUnavailable`.
- GHN addresses: GHN's create and fee APIs want its own district and ward ids. The GHN client resolves the province, district and ward by name through GHN's master data (`/master-data/province`, `/district`, `/ward`), case- and accent-insensitive; no match is `carrier.ErrAddressUnknown` (422 `carrier_address_unknown`). This is the plan's guess at the least surprising behaviour; staging decides.

// Package carrier makes and reads shipments at the carriers a seller links,
// GHTK and GHN, with the seller's own token. Fake stands in for both in
// development and tests.
package carrier

import (
	"context"
	"errors"
	"strings"
	"unicode/utf8"
)

// Carrier is a carrier's code.
type Carrier string

const (
	GHTK Carrier = "ghtk"
	GHN  Carrier = "ghn"
)

// Status is where a parcel is, in ShopNexus's words.
type Status string

const (
	StatusPendingPickup Status = "pending_pickup"
	StatusInTransit     Status = "in_transit"
	StatusDelivered     Status = "delivered"
	StatusFailed        Status = "failed"
)

var (
	ErrNotFound       = errors.New("carrier: no such shipment in this account")
	ErrUnavailable    = errors.New("carrier: no carrier in this stack")
	ErrLoginFailed    = errors.New("carrier: the carrier refused the account")
	ErrNotCancellable = errors.New("carrier: the carrier has picked the parcel up")
	ErrAddressUnknown = errors.New("carrier: the carrier does not know the address")
)

// Credentials are what a seller types to link an account: GHTK's email and
// password, or GHN's token and ShopId.
type Credentials struct {
	Email, Password string
	Token, ShopID   string
}

// Account is a linked account as the clients use it.
type Account struct {
	Token    string
	ShopCode string
}

// Linked is what linking returns: the shop code to show and the token to
// keep.
type Linked struct {
	ShopCode string
	Token    string
}

// PickupPoint is a pickup point the seller registered at the carrier.
type PickupPoint struct {
	ID, Name, Phone, Address string
}

// Place is an address by names, as the carriers take them.
type Place struct {
	Name, Phone, Street, Commune, Province string
}

// Pickup is where the carrier takes the parcel: a pickup point of the
// seller's at the carrier, or a place.
type Pickup struct {
	PointID string
	Place   *Place
}

// CreateInput is a shipment to make on the seller's account. OrderCode is
// ShopNexus's order code; a retry with the same code makes no second
// shipment.
type CreateInput struct {
	OrderCode   string
	Recipient   Place
	Pickup      Pickup
	Item        string
	COD         int64
	WeightGrams int
	Service     string // standard or express
	Option      string // home or post_office
}

// QuoteInput is a shipment to price.
type QuoteInput struct {
	Recipient   Place
	Pickup      Pickup
	WeightGrams int
	Service     string
	Value       int64
}

// Created is a new shipment's tracking code and fee, in đồng.
type Created struct {
	TrackingCode string `json:"tracking_code"`
	Fee          int64  `json:"fee"`
}

// Parcel is what a carrier tells of a shipment.
type Parcel struct {
	RecipientName string
	District      string
	COD           int64
	Status        Status
	Fee           *int64
}

// Client is one carrier, called with a seller's account.
type Client interface {
	Link(ctx context.Context, c Credentials) (Linked, error)
	Pickups(ctx context.Context, a Account) ([]PickupPoint, error)
	Quote(ctx context.Context, a Account, in QuoteInput) (int64, error)
	Create(ctx context.Context, a Account, in CreateInput) (Created, error)
	Lookup(ctx context.Context, a Account, code string) (Parcel, error)
	// Cancel calls a shipment off; ErrNotCancellable once the carrier has
	// the parcel. A second call changes nothing.
	Cancel(ctx context.Context, a Account, code string) error
}

// mask keeps each word's first letter: "Vân Nguyễn" → "V** N*****".
func mask(name string) string {
	words := strings.Fields(name)
	for i, w := range words {
		r, size := utf8.DecodeRuneInString(w)
		words[i] = string(r) + strings.Repeat("*", utf8.RuneCountInString(w[size:]))
	}
	return strings.Join(words, " ")
}

Numbers that GHTK may quote are read through `type flexInt int64` with `UnmarshalJSON` accepting `"30400"` and `30400`.

```go
package carrier

import (
	"bytes"
	"context"
	"encoding/json"
	"errors"
	"fmt"
	"net/http"
	"net/url"
	"strconv"
	"strings"
)

// GHTK reads and makes shipments at GHTK with each seller's shop token.
// PartnerToken is ShopNexus's B2C token, used only to link accounts.
type GHTK struct {
	BaseURL      string
	PartnerToken string
	ClientSource string
	HTTP         *http.Client
}

var _ Client = GHTK{}

// flexInt reads a number GHTK sends as 30400 or "30400".
type flexInt int64

func (n *flexInt) UnmarshalJSON(b []byte) error {
	s := strings.Trim(string(b), `"`)
	if s == "" || s == "null" {
		*n = 0
		return nil
	}
	v, err := strconv.ParseInt(s, 10, 64)
	*n = flexInt(v)
	return err
}

type ghtkReply struct {
	Success bool   `json:"success"`
	Message string `json:"message"`
}

func (g GHTK) do(ctx context.Context, method, path, token string, body, out any) (int, error) {
	var rd *bytes.Reader
	if body != nil {
		b, err := json.Marshal(body)
		if err != nil {
			return 0, fmt.Errorf("encode %s: %w", path, err)
		}
		rd = bytes.NewReader(b)
	} else {
		rd = bytes.NewReader(nil)
	}
	req, err := http.NewRequestWithContext(ctx, method, g.BaseURL+path, rd)
	if err != nil {
		return 0, fmt.Errorf("request %s: %w", path, err)
	}
	req.Header.Set("Token", token)
	req.Header.Set("X-Client-Source", g.ClientSource)
	req.Header.Set("Content-Type", "application/json")
	res, err := g.HTTP.Do(req)
	if err != nil {
		return 0, fmt.Errorf("call GHTK %s: %w", path, err)
	}
	defer res.Body.Close()
	if res.StatusCode != http.StatusOK {
		return res.StatusCode, fmt.Errorf("GHTK %s: HTTP %d", path, res.StatusCode)
	}
	if err = json.NewDecoder(res.Body).Decode(out); err != nil {
		return res.StatusCode, fmt.Errorf("decode GHTK %s: %w", path, err)
	}
	return res.StatusCode, nil
}

func (g GHTK) Link(ctx context.Context, c Credentials) (Linked, error) {
	var out struct {
		ghtkReply
		Data struct{ Code, Token string } `json:"data"`
	}
	code, err := g.do(ctx, http.MethodPost, "/services/shops/token", g.PartnerToken, map[string]string{"email": c.Email, "password": c.Password}, &out)
	if code == http.StatusForbidden {
		return Linked{}, fmt.Errorf("GHTK refused ShopNexus's partner token: %w", err)
	}
	if err != nil {
		return Linked{}, err
	}
	if !out.Success || out.Data.Token == "" {
		return Linked{}, ErrLoginFailed
	}
	return Linked{ShopCode: out.Data.Code, Token: out.Data.Token}, nil
}

func (g GHTK) Pickups(ctx context.Context, a Account) ([]PickupPoint, error) {
	var out struct {
		ghtkReply
		Data []struct {
			ID      string `json:"pick_address_id"`
			Address string `json:"address"`
			Tel     string `json:"pick_tel"`
			Name    string `json:"pick_name"`
		} `json:"data"`
	}
	if _, err := g.do(ctx, http.MethodGet, "/services/shipment/list_pick_add", a.Token, nil, &out); err != nil {
		return nil, err
	}
	pts := make([]PickupPoint, 0, len(out.Data))
	for _, p := range out.Data {
		pts = append(pts, PickupPoint{ID: p.ID, Name: p.Name, Phone: p.Tel, Address: p.Address})
	}
	return pts, nil
}

func (g GHTK) Quote(ctx context.Context, a Account, in QuoteInput) (int64, error) {
	q := url.Values{"province": {in.Recipient.Province}, "ward": {in.Recipient.Commune}, "address": {in.Recipient.Street},
		"weight": {strconv.Itoa(in.WeightGrams)}, "value": {strconv.FormatInt(in.Value, 10)}, "transport": {ghtkTransport(in.Service)}}
	pickupQuery(q, in.Pickup)
	var out struct {
		ghtkReply
		Fee struct {
			Fee      flexInt `json:"fee"`
			Delivery bool    `json:"delivery"`
		} `json:"fee"`
	}
	if _, err := g.do(ctx, http.MethodGet, "/services/shipment/fee?"+q.Encode(), a.Token, nil, &out); err != nil {
		return 0, err
	}
	if !out.Success || !out.Fee.Delivery {
		return 0, ErrAddressUnknown
	}
	return int64(out.Fee.Fee), nil
}

func (g GHTK) Create(ctx context.Context, a Account, in CreateInput) (Created, error) {
	order := map[string]any{
		"id": in.OrderCode, "name": in.Recipient.Name, "tel": in.Recipient.Phone, "address": in.Recipient.Street,
		"province": in.Recipient.Province, "ward": in.Recipient.Commune, "hamlet": "Khác",
		"pick_money": in.COD, "value": in.COD, "is_freeship": 0, "transport": ghtkTransport(in.Service),
		"pick_option": map[string]string{"home": "cod", "post_office": "post"}[in.Option],
	}
	if in.Pickup.PointID != "" {
		order["pick_address_id"] = in.Pickup.PointID
	}
	if p := in.Pickup.Place; p != nil {
		order["pick_name"], order["pick_tel"], order["pick_address"] = p.Name, p.Phone, p.Street
		order["pick_province"], order["pick_ward"] = p.Province, p.Commune
	}
	body := map[string]any{
		"products": []map[string]any{{"name": in.Item, "weight": float64(in.WeightGrams) / 1000, "quantity": 1}},

package domain

import (
	"crypto/aes"
	"crypto/cipher"
	"crypto/rand"
	"errors"
	"fmt"
)

// ErrSealedToken is a token that does not open under the key: another
// environment's key, or a damaged row.
var ErrSealedToken = errors.New("shipping: the token does not open under this key")

// Seal encrypts a carrier token with AES-GCM under key (32 bytes).
func Seal(key []byte, token string) (sealed, nonce []byte, err error) {
	block, err := aes.NewCipher(key)
	if err != nil {
		return nil, nil, fmt.Errorf("cipher: %w", err)
	}
	gcm, err := cipher.NewGCM(block)
	if err != nil {
		return nil, nil, fmt.Errorf("gcm: %w", err)
	}
	nonce = make([]byte, gcm.NonceSize())
	if _, err = rand.Read(nonce); err != nil {
		return nil, nil, fmt.Errorf("nonce: %w", err)
	}
	return gcm.Seal(nil, nonce, []byte(token), nil), nonce, nil
}

// Open decrypts a sealed token; ErrSealedToken when it does not open.
func Open(key, sealed, nonce []byte) (string, error) {
	block, err := aes.NewCipher(key)
	if err != nil {
		return "", fmt.Errorf("cipher: %w", err)
	}
	gcm, err := cipher.NewGCM(block)
	if err != nil {
		return "", fmt.Errorf("gcm: %w", err)
	}
	plain, err := gcm.Open(nil, nonce, sealed, nil)
	if err != nil {
		return "", ErrSealedToken
	}
	return string(plain), nil
}

func (s *Shipping) account(ctx context.Context, owner uuid.UUID, c string) (carrier.Client, carrier.Account, error) {

		return nil, carrier.Account{}, err

func carrierError(err error) error {
	switch {
	case errors.Is(err, carrier.ErrUnavailable):
		return domain.ErrUnavailable
	case errors.Is(err, carrier.ErrLoginFailed):
		return domain.ErrLoginFailed
	case errors.Is(err, carrier.ErrAddressUnknown):
		return domain.ErrAddressUnknown
	}
	return err
}

// 200 for any report once the secret matches, so the carrier does not

func (h *Handler) Webhook(w http.ResponseWriter, r *http.Request) {

```go
// Poll reads a shipped order's shipment from its carrier and moves the
// order as ShipmentUpdates would, then polls again Waits.Poll later while
// the order stays shipped. It is the safety net under the webhooks.
func (s OrderTimers) Poll(ctx restate.Context, ref OrderRef) error {
	m, err := systemLoadStep(ctx, s.Deals, ref.DealID)
	if err != nil {
		return err
	}
	o := domain.RestoreDeal(m.Deal).Order()
	if o == nil || o.ID != ref.OrderID || o.Status != domain.OrderShipped || o.Shipment == nil {
		return nil // the order moved on
	}
	sh := *o.Shipment
	read, err := restate.Run(ctx, func(rc restate.RunContext) (string, error) {
		p, readErr := s.Deals.shipping.Lookup(rc, m.Deal.SellerID, carrier.Carrier(sh.Carrier), sh.TrackingCode)
		if errors.Is(readErr, carrier.ErrNotFound) || errors.Is(readErr, shippingdomain.ErrNotLinked) {
			return "", nil
		}
		return string(p.Status), readErr
	})
	if err != nil {
		return fmt.Errorf("read the shipment at %s: %w", sh.Carrier, err)
	}
	if read != "" && read != string(sh.Status) {
		if _, err = restate.Service[ShipmentResult](ctx, s.Deals.prefix+shipmentUpdates, flowHandler).
			Request(ShipmentSignal{TrackingCode: sh.TrackingCode, Status: domain.ShipmentStatus(read)}); err != nil {
			return fmt.Errorf("move the order: %w", err)
		}
	}
	restate.ServiceSend(ctx, s.ServiceName(), "Poll").Send(ref, restate.WithDelay(s.Deals.waits.Poll))
	return nil
}
```
