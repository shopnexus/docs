# Plan: `ai` as the AI hub

Spec: `superpowers/specs/2026-11-17-ai-hub-design.md`.

Goal: the `ai` repo owns the LiteLLM gateway and the self-hosted models and
deploys both through its own chart; LLMs and `embed-text` go through
OpenRouter; TEI is gone; each embedder can be off; dev runs it.

## Tasks

1. Measure (spec, "Measured first"). Needs an OpenRouter key.
   - OpenRouter `baai/bge-m3` against `bge-m3-reference.json` (from the
     `feat/bge-m3` branch): cosine per text, the long text apart; 16 inputs
     in one request; 1024 dimensions.
   - LiteLLM (the pinned image) in front of OpenRouter: `usage` reaches the
     client; an upstream 402 (a stub upstream) reaches the client as a
     status the server and the agent treat as a budget error.
   - Decide the text cut: the characters that keep a listing text under
     2048 tokens, measured on the reference texts.
   Results (2026-11-17):
   - OpenRouter serves `baai/bge-m3` from two providers. DeepInfra (fp32)
     matches TEI at a cosine of 0.999999 on every reference text under 2048
     tokens; Parasail gives 0.996. `embed-text` pins DeepInfra with
     `provider: {order: [DeepInfra], allow_fallbacks: false}` in LiteLLM's
     `extra_body`, which LiteLLM v1.108.0 forwards (checked: the Parasail
     pin gave Parasail's vectors through it). 16 inputs in one request: 2.3 s.
   - The text over 2048 tokens gives 0.90 (no cut at 2048 upstream), and a
     text with the literal special tokens `<s>`, `<mask>` gives 0.93. The
     server already cuts listing text at `EmbeddingTextMax` = 2000
     characters, under 2048 tokens, so no further cut is needed and
     `EMBED_TEXT_VERSION` stays.
   - LiteLLM passes OpenRouter's `usage` (tokens and `cost`) through for
     chat and embeddings, and passes an upstream 402 through as HTTP 402,
     code `"402"`. The server's embed client retries a 402 (good); its LLM
     client treats any 4xx but 429 as a refused input, so a 402 must join
     429 there. The agent's `isBudgetError` knows only LiteLLM's own
     `budget_exceeded`, so it must also take a 402 (task 4b).
2. `ai`: embedders optional. `AI_EMBED_MODELS` may be empty: no embed
   model loads and `/v1/embeddings` answers 404 `model_not_found`. Config
   test, README.
3. `ai`: the chart. `chart/` with `ai-gateway` (LiteLLM Deployment,
   Service, ConfigMap from values), the key Job, `ai-models` (today's
   `infra/stack/templates/ai.yaml`), their NetworkPolicy labels, and the
   helm-unittest tests moved from `infra/stack/tests` (litellm, ai). Values:
   aliases, keys, budgets, models, `aiModels.embedModels` (empty = off),
   memory. `gateway/` holds nothing the chart cannot render; the config
   template lives in the chart. Upstream `openrouter` via LiteLLM's
   provider chosen in task 1. Services `ai-gateway` and `ai-models`.
   `helm unittest` and `helm lint` in a CI step of `build.yml`.
4. server: embedders optional (`EMBED_TEXT_MODEL`, `EMBED_IMAGE_MODEL`
   empty = off, with their base URL, version and floor allowed empty);
   `ListingEmbed` skips an off kind without retry; search leaves out the
   lists of an off kind; `photo=` with images off is 503
   `photo_search_unavailable`; listing text cut before `embed-text` as
   task 1 decides. Config, discovery and handler tests. `.env.example`
   (OpenRouter for the LLMs and `embed-text`), compose profile `models`
   runs `ai-models` only, README, ARCHITECTURE.
4b. agent (`~/shopnexus/agent`, another session's area: a branch, and a
   note to that session): `isBudgetError` takes status 402 or code
   `"402"` as a spent budget.
5. umbrella `infra`: delete `litellm.yaml`, `litellm-keys.yaml`,
   `ai.yaml`, `tei.yaml` and their tests and values from `infra/stack`;
   keep the `litellm` database and role; `_server-env.tpl` points at
   `ai-gateway` and `ai-models`; NetworkPolicies name the new apps;
   `infra/argocd/ai.yaml` with an Application per stack (multi-source:
   the `ai` chart at `main`, values `infra/ai/values-<stack>.yaml`), sync
   wave after the stack; Image Updater moves `ai-models`' image to the
   new Application; `infra/cmd/seal` renames `LLM_UPSTREAM_API_KEY` to
   `OPENROUTER_API_KEY`; `check.sh`; root compose without TEI and with
   `ai-models-<stack>`; `smoke-models.hurl` through `ai-gateway`.
6. docs: the cluster pages `index` and `llm-gateway` (en, vi), the
   `ai` README.
7. Deploy dev (each push confirmed with the user): push `ai`, server,
   umbrella, docs; seal dev's `OPENROUTER_API_KEY`; apply
   `ai-dev` and sync `stack-dev` by hand (auto-sync is off since
   2026-11-17); `ai-models` without SigLIP 2; smoke tests; the server's
   search works on BM25 and text vectors.
